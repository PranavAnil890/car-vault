
# 🚗 CarVault – Smart Car Ownership & Service Platform

CarVault is a MERN Stack-based web application designed to simplify car ownership and vehicle service management through a single platform.

## 🚀 Features

- User Authentication and Authorization
- Role-based access (Customer, Service Center, Admin)
- Vehicle Management
- Service Center Management
- Service Booking
- Time Slot Management
- Booking Status Tracking
- Service History Management
- Customer Reviews and Ratings
- Admin Dashboard

## 🛠️ Technologies Used

### Frontend
- React.js
- JavaScript
- HTML5
- CSS3
- Bootstrap

### Backend
- Node.js
- Express.js
- REST API

### Database
- MongoDB
- Mongoose

### Tools
- Git
- GitHub
- VS Code
- Postman

## 👥 User Roles

1. Customer – Manage vehicles, book services, track bookings and view service history.
2. Service Center – Manage services, time slots and customer bookings.
3. Admin – Manage customers and service centers.

## ⚙️ Installation and Setup

### 2. Backend Setup

```bash
cd carvault-backend
npm install
npm start
```

### 3. Frontend Setup

Open another terminal:

```bash
cd carvault-frontend/car-project
npm install
npm run dev
```
